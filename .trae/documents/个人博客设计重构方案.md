# 个人博客设计重构方案 - Pencil 设计稿

## 当前设计分析

### 现有结构
- **框架**: Hexo 静态博客，使用 chic 主题
- **配色**: 支持明暗双主题，当前深色主题 #000 背景，浅色 #f5f7fb
- **布局**: 顶部导航 + 内容区 + 页脚，首页已经采用终端风格
- **页面**: 首页、文章归档、文章详情、分类、标签、关于、友链、INS 相册

### 现有问题
- 视觉层次不够清晰，信息密度分布可以优化
- 卡片间距和内边距需要调整，提升呼吸感
- 代码块高亮可以更加美观
- 缺乏现代化的交互设计细节

## 重新设计方案

### 设计风格
- **主题**: 深色开发者风格，延续现有的终端气质
- **配色**: 深蓝黑色背景 (#0a0e17)，天蓝色强调色 (#38bdf8)，合理层次对比度
- **字体**: Inter 无衬线字体 + IBM Plex Mono 代码字体
- **语言**: 中文内容，保持清晰可读性

### 页面设计概览

#### 1. 首页 (Homepage)
- 顶部固定导航栏，左侧 Logo 右侧导航菜单 + 主题切换
- 首屏采用左右对称布局：
  - 左侧：个人介绍 + 核心标语 + 操作按钮 + 统计数据
  - 右侧：终端风格卡片展示头像 + 统计信息
- 延续并优化现有的开发者终端美学

#### 2. 文章归档页 (Archive)
- 页面标题 + 统计信息
- 文章列表采用卡片式设计，每篇文章显示：
  - 文章标题
  - 简介摘要
  - 日期和分类标签
- 底部分页控件，当前页高亮

#### 3. 文章详情页 (Post Detail)
- 左侧：文章主体内容
  - 分类标签 → 标题 → 元信息（日期、标签）→ 正文 → 标签云
  - 正文支持多级标题、段落、代码块
- 右侧：固定目录侧边栏（大屏幕可见）
  - 滚动时高亮当前章节

### 设计特点
1. **保持开发者气质**：延续终端风格，但提升视觉层次
2. **现代简约**：去除多余装饰，聚焦内容
3. **清晰信息层级**：通过颜色、大小、间距建立阅读节奏
4. **舒适阅读体验**：合理行高、字间距、边距
