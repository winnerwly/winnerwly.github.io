# 实战：用 Trae + Claude 从零开发一个功能模块

前面几篇文章讲了很多理论和技巧，这篇我们来个真刀真枪的实战。我带你走一遍，如何用 Trae + Claude 从零开始开发一个完整功能。

## 需求：开发一个简单的待办事项 API

我们就拿一个经典例子来练手：开发一个 RESTful API 的待办事项服务。需求很清晰：

功能需求：
- ✅ 获取所有待办事项列表
- ✅ 按 ID 获取单个待办事项
- ✅ 创建新的待办事项
- ✅ 更新待办事项（标题、完成状态）
- ✅ 删除待办事项
- ✅ 基本的错误处理

技术栈约定：
- Node.js + Express
- 不用数据库，用内存数组存储（简单起见）
- 接口返回 JSON
- 端口 3000

好，需求就这么多，现在开始。

```javascript
let todos = [
  { id: 1, title: 'Learn Trae AI', completed: false, createdAt: new Date() },
  { id: 2, title: 'Build a todo API', completed: false, createdAt: new Date() }
];

let nextId = 3;

// 获取所有
function findAll() {
  return todos;
}

// 按ID查找
function findById(id) {
  id = Number(id);
  return todos.find(todo => todo.id === id);
}

// 创建
function create(title) {
  const todo = {
    id: nextId++,
    title,
    completed: false,
    createdAt: new Date()
  };
  todos.push(todo);
  return todo;
}

// 更新
function update(id, data) {
  id = Number(id);
  const index = todos.findIndex(todo => todo.id === id);
  if (index === -1) return null;
  
  todos[index] = {
    ...todos[index],
    ...data
  };
  return todos[index];
}

// 删除
function remove(id) {
  id = Number(id);
  const index = todos.findIndex(todo => todo.id === id);
  if (index === -1) return null;
  
  const deleted = todos[index];
  todos.splice(index, 1);
  return deleted;
}

module.exports = {
  findAll,
  findById,
  create,
  update,
  remove
};
```

**我的检查**：
- ✅ 函数都齐了
- ✅ ID 类型转换做了，防止字符串问题
- ✅ 默认有初始数据，方便测试
- ✅ 模块导出正确

等等，让我看看代码...哦，目录结构的问题！app.js 在根目录，routes 也在根目录，路径是对的啊。哦，我看看 Claude 写的路径：

原来 Claude 写的路径对，但是我创建目录了吗？我一看，哦，我忘记创建 `routes/` 和 `controllers/` 目录了！😅

这个怪我，不是 Claude 的错。创建完目录，再跑：

## 经验总结：哪些环节 AI 做，哪些要人工把控

做完这个小项目，我总结一下分工：

### 👏 AI 做得很好的环节：

1. **项目结构搭建** —— 框架性代码 AI 写得又快又对
2. **CRUD 样板代码** —— 增删改查这种重复活，AI 比人写得快
3. **错误处理** —— AI 记得处理各种边界 case，比新手强
4. **写文档** —— README 和接口示例，AI 写得很规范
5. **代码风格统一** —— 保持一致的缩进、命名、注释

### 👋 人需要把控的环节：

1. **需求澄清** —— 你得说清楚你到底要什么
2. **方案评审** —— AI 出的方案对不对，合不合现有项目，你得拍板
3. **Bug 排查** —— 运行错了，你得告诉 AI 错误日志，帮它定位
4. **业务逻辑正确性** —— 这个功能对不对，符不符合需求，人说了算
5. **最终验收** —— 好不好用，能不能上线，人拍板

## 遇到问题怎么办？实战中的几个小插曲

### 插曲 1：AI 忘记导入模块了怎么办？

某次生成代码，AI 用了 `express` 但是忘记 `require` 了。运行报错。

**解法**：把错误信息复制给 AI：

```
运行报错了：ReferenceError: express is not defined
看一下哪错了，帮我修一下。
```

AI 马上就找到问题，加上 `const express = require('express');`，搞定。

### 插曲 2：逻辑不对怎么办？

比如我说要内存存储，AI 想给我加 MongoDB。

**解法**：直接说：

```
我们约定好了用内存数组存储，不用 MongoDB，请重新来一个版本。
```

AI 马上就改了，没问题。

### 插曲 3：代码风格和我的项目不匹配怎么办？

**解法**：提前告诉 AI：

```
项目用 2 空格缩进，不要分号，请按照这个风格写。
```

或者生成完了再改：

```
帮我把这个文件改成 2 空格缩进，去掉分号。
```

AI 分分钟改好。
