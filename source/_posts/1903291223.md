# 更换yum源能有效的提高安装时下载包的速度

<!-- more -->

>第一步: 备份原有镜像源

```
mv /etc/yum.repos.d/CentOS-Base.repo /etc/yum.repos.d/CentOS-Base.repo.backup
```

>第二步: 下载ailiyun的yum源配置文件到/etc/yum.repos.d/

```
wget -O /etc/yum.repos.d/CentOS-Base.repo http://mirrors.aliyun.com/repo/Centos-7.repo
```

>第三步: 重新设置缓存

```
yum clean all
yum makecache
```

>第四步: 查看yum源xinxi

```
yum repolist
```

>到此已经配置完成,本方法仅适用于CentOs7

>附:
```
yum -y update
# 升级所有包同时也升级软件和系统内核
```
