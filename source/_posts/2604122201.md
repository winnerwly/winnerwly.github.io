# 什么是 Skills？

在软件开发中，我们经常听到「技能」这个词，但当我们在代码里看到 `skills` 或者 `skill` 这样的命名时，它到底指的是什么？

这篇文章从编程设计的角度来聊聊这个概念。

# 从字面含义出发

「Skill」直译过来是**技能**、**技巧**。在日常生活中，技能是指「完成某项任务的能力」。比如：

- 阅读是一种技能
- 游泳是一种技能
- 编程是一种技能

放到代码世界里，这个概念其实是一样的：**Skill 代表一种「能做某事」的能力**。

# 常见代码场景

## 1. 技能列表：角色/AI 拥有哪些能力

在游戏、AI 助手、或者权限系统中，我们常常会看到这样的定义：

```ts
interface User {
  id: number;
  name: string;
  skills: string[]; // 当前用户掌握的技能
}

const aiAssistant: User = {
  id: 1,
  name: "GPT",
  skills: ["chat", "code", "translation"],
};
```

这里的 `skills` 就是一个**能力清单**，用来回答「这个东西能干什么？」。

## 2. 技能接口：多态设计

在面向对象设计中，我们可以把不同的「技能」抽成接口：

```ts
interface Skill {
  name: string;
  execute(ctx: Context): Promise<void>;
}

class ChatSkill implements Skill {
  name = "chat";
  async execute(ctx: Context) {
    // 处理对话
  }
}

class CodeGenSkill implements Skill {
  name = "code-gen";
  async execute(ctx: Context) {
    // 生成代码
  }
}
```

这种设计的好处是：

- **开闭原则**：新增技能只需要加新类，不影响已有代码
- **可组合**：一个 agent 可以挂载任意多个技能
- **可插拔**：方便做动态加载、权限控制

这也是现在 AI Agent 框架中非常常见的模式。

## 3. 技能配置：参数化能力

有时候技能不仅要说明「有什么能力」，还要带配置：

```ts
interface SkillConfig {
  enabled: boolean;
  level: number; // 技能等级
  cooldown?: number; // 冷却时间
}

type Skills = Record<string, SkillConfig>;

class Player {
  skills: Skills = {
    attack: { enabled: true, level: 5 },
    heal: { enabled: true, level: 3 },
    teleport: { enabled: false, level: 0 },
  };
}
```

这种写法常见于游戏角色、用户权限功能开关等场景。

# 为什么要用 Skills 这个词？

相比于 `abilities`、`capabilities`、`permissions`，Skills 强调的是：

| 概念 | 侧重 |
|------|------|
| Skills | 「已经学会的」、「可以使用的」能力 |
| Abilities | 天生的、潜在的能力 |
| Permissions | 权限，由外部授予的许可 |

所以，当你的语境是「这个实体学会了什么，可以使用什么」，用 `skills` 比 `abilities` 更贴切。

# Trae 中的 Skills

你现在用的 Trae AI 编辑器里，也有「Skills」这个概念。它指的是：

> 预先定义好的、专门处理某一类任务的能力模块。

比如：

- 有些 Skill 擅长分析代码结构
- 有些 Skill 擅长生成特定框架的代码
- 有些 Skill 擅长做代码审查

当你输入提示时，Trae 会根据你的问题选择合适的 Skill 来处理。这种设计让能力可以持续迭代和扩充，不影响核心流程。

# 小结

在代码中，`skills` 通常就是：

- **一份能力清单**，告诉你当前对象能做什么
- 也可能是**一组可插拔的能力模块**，方便组合和扩展
- 本质上是**单一职责 + 组合优于继承**设计思想的体现

看到这里，下次你在代码里见到 `skills` 这个单词，应该就不会困惑它到底是什么意思了。

---

一句话总结：**Skill = 「能做一件事」的抽象，skills = 多个这种抽象的集合**。
