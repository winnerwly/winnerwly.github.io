你好，我是 Mr.w，GitHub 上叫 winnerwly。一个总喜欢搞点乱七八糟东西的前端。

平时主要写 JavaScript 和 Vue。遇到重复的活儿，就用 Node.js 写点脚本。之前折腾过命令行选择工具，也给图片压缩写过一个命令行工具。有些东西写完就够自己用了，有些值得留篇文章，下次遇到还能翻出来。

## 关于这个博客

这里有早些年写的 JavaScript 笔记，也有后来做项目时留下的记录，比如怎么用 pnpm 管理 monorepo，怎么给 NestJS 加缓存。最近也在写 AI 编程，聊聊需求怎么说清楚、代码改完怎么验，以及哪些坑是自己踩过才记住的。

如果你是为某个问题来的，可以先翻[文章归档](/archives/)或[按分类找](/category/)。旧文章里的版本和写法有些年头了，照着试之前可以先看一眼发布日期。
