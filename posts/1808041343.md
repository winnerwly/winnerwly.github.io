这几天在查看nginx日志的时候 总是需要输入
```bash
tail -f 20 /hemo/wwwlogs/www.demo.com.log
# 或者
tail -n 200 /hemo/wwwlogs/www.demo.com.log
```
命令不是很长,但是感觉这样经常输入很麻烦,就想着看能不能找一个简单一点方法,将这个命令写成一个脚本

然后查了下,将命令写到一个shell脚本中执行就能实现这种效果

想要执行命令的时候执行shell脚本文件就可以,再也不用敲那么长长的一串了

首先需要创建一个脚本文件
我是直接用vim showlog.sh的方式创建的

将命令输入
```bash

#!/bin/bash

tail -n 200 /home/wwwlogs/www.demo.com.log

```

保存,此时还不能执行文件(文件的读写权限不够)

```
chmod +x ./showlog.sh #使脚本具有执行权限

./showlog.sh #执行脚本文件
```

以后就是简单执行脚本文件了
