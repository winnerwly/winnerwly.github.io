### 这里的实现使用的是一个npm库 ora
安装ora包
```shell
npm install ora@5.4.1
# or
yarn add ora@5.4.1
```

### loading效果 示例
```js
const ora = require('ora)

const spinner = ora('Loading unicorns').start();

setTimeout(() => {
  spinner.stop()
}, 1000);
```

### 完成进度 示例
```js
const ora = require('ora')

const spinner = ora('目录解析中...').start()

setTimeout(() => {
  spinner.succeed(`压缩完成`)
}, 1000)

setTimeout(() => {
  spinner.fail(`压缩失败`)
}, 2000)
```
