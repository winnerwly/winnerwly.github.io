>1 我们需要一个我们的开发环境(node,npm)
npm的源很慢,建议设置淘宝源,或者使用cnpm或者yarn

>安装cnpm
```
npm install -g cnpm --registry=https://registry.npm.taobao.org
```

>npm设置淘宝源
```
npm config set registry https://registry.npm.taobao.org
```

>2 我们需要安装angular-cli
```
npm install -g @angular/cli
```

>3 开始初始化一个项目
```
ng new my-ng-app --style less
# --style less 表示项目使用less预编译语言
```

>4 初始化NG-ZORRO(antd)的配置 (这里是一键配置antd)
```
# cd my-ng-app
ng add ng-zorro-antd
# ng命令好像默认调用的是npm 如果你在初始化项目的时候中断了依赖下载,使用yarn继续 则不能初始化NG-ZORRO
# 有毒的操作
```

>5 到此环境已经配置好了 
```
ng serve --port 0 --open
# 建议讲这行命令配置到package.json中 这个可以使用yarn start了
```

>! 编译
```
ng build --prod
```
