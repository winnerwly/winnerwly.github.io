# thinkphp项目部署-坑
```
root  /home/wwwroot/t5/public; 

绑定的是pubic 目录, 如果锁定这个是根目录, 那么上层的application就访问不到, 锁定了权限. 

这是因为/usr/local/nginx/conf/vhost/ 下面有一个fastcgi.conf的配置文件,

最后一句, 锁定只在当前目录活动了

#fastcgi_param PHP_ADMIN_VALUE "open_basedir=$document_root/:/tmp/:/proc/";

所以这一句前面加上#, 注释掉就可以用了
```
