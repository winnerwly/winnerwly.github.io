# git rebase 使用记录

<!-- more -->

## 有的时候不必要的commit 我们可以进行合并处理,这样可以让我们的git log 变的清晰起来

> 合并commit记录 

![日志](01.png)

### 这只是第一步操作

```bash
# git rebase -i [commit-id|origin/HEAD]

git rebase -i 4b351d893da56a93ab9bceba855321bf384b4f27
# 将4b351d893da56a93ab9bceba855321bf384b4f27记录之后的记录合并

git rebase -i origin/HEAD 
# 将未提交远程仓库的记录合并

```
