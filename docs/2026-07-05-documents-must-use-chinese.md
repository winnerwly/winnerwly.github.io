# 文档语言规范变更开发文档

## 需求概述

用户要求：项目中的所有文档都需要使用中文编写。

该要求需要纳入项目级规范，确保后续贡献指南、开发文档、需求分析文档、总结文档等均默认使用中文。

## 当前状态分析

- `AGENTS.md` 当前主要使用英文编写。
- `docs/README.md` 当前使用英文编写。
- 项目已规定所有开发文档统一存放在 `docs/` 目录下。
- 新规则需要与现有“先写开发文档、确认后再开发、完成后回顾总结”的流程保持一致。

## 实施计划

1. 将 `AGENTS.md` 中的相关说明改为中文，或至少新增明确中文规则。
2. 将 `docs/README.md` 改为中文。
3. 明确规定：所有项目文档、开发文档、需求分析、开发总结都必须使用中文编写。
4. 保留必要的技术名词、命令、路径、文件名原文，例如 `npm run build`、`AGENTS.md`、`docs/`。

## 影响文件

- `AGENTS.md`
- `docs/README.md`

## 验证计划

- 检查上述文件内容是否明确写入“所有文档必须使用中文”。
- 检查文档主体是否为中文。
- 本次为文档规则变更，不需要运行 Hexo 构建。

## 风险与取舍

- 技术命令、路径、文件名保持英文或原格式是必要的，不应强行翻译。
- 历史文章内容不在本次规则变更范围内；该规则主要约束项目文档和后续开发流程文档。
