# 文章详情排版优化

## 变更内容

调整文章详情页的标题字号和长标题换行，统一正文各级标题、列表缩进和代码块样式，并压缩手机端元信息的行间距。正文起首一级标题与文章标题相同时合并展示，原标题锚点移到页首标题，目录从正文的章节开始。

## 影响范围

改动限于文章详情模板及其专属样式。文章 Markdown、公共导航和其他页面沿用原有实现。

## 验证结果

`npm run build` 和 `git diff --check` 通过。Chrome 在 360、768 和 1280 像素宽度下抽查当前文章和含表格文章，两篇均成功加载且无页面横向溢出。当前文章只显示一次标题并保留原锚点，章节目录在窄屏展开后及宽屏上可见。
