# 顶部导航栏未居中对齐修复

| 项目 | 内容 |
| --- | --- |
| 变更类型 | 缺陷修复（样式，简单小需求，快速通道） |
| 变更日期 | 2026-07-18 |
| 确认方式 | 缺陷修复快速通道，事后记录 |

## 一、变更背景

桌面端顶部导航栏（`.site-nav`）的三列布局存在视觉偏移：导航链接组（首页 / 文章 / INS / 分类 / 标签 / 关于 / 友链）整体未在视口水平居中，明显偏向右侧。

根因：`.site-nav-shell` 采用 `grid-template-columns: auto minmax(0, 1fr) auto` 三列网格，左列 `.site-brand`（“W 前端小站”，约 150px）远宽于右列 `.site-nav-actions`（桌面端仅有 40px 的主题切换按钮，菜单按钮 `display:none`）。中间列吸收全部剩余空间并在「自身内部」居中内容，由于左右两列宽度不等，剩余空间的中心并不等于视口中心，导致链接组整体向右偏移约 50px。

## 二、变更内容

仅修改 `themes/chic/source/css/custom.styl`，未改动模板（`header.ejs`）与脚本：

1. `.site-nav-shell` 增加 `margin: 0 auto`，使导航外壳在视口中水平居中（与 `.main .container` 的 `margin: 0 auto` 一致）。原规则只有 `max-width: 1360px` 无 auto 外边距，导致宽屏（>1360px）下整个导航条贴左、与居中的正文错位。
2. `.site-nav-shell` 的 `grid-template-columns` 由 `auto minmax(0, 1fr) auto` 改为 `minmax(0, 1fr) auto minmax(0, 1fr)`，使左右两个侧轨平分剩余空间，中间 `auto` 轨按内容宽度精确落在容器正中。
3. `.site-brand` 增加 `justify-self: start`，品牌固定贴左。
4. `.site-nav-actions` 增加 `justify-self: end`，操作区固定贴右（原有的 `justify-content: flex-end` 仅控制其内部子元素，新增的 `justify-self: end` 控制网格项自身在轨内的定位）。

移动端（`max-width: 1023px`）断点保持原 `minmax(0, 1fr) auto` 两列布局不变，链接列隐藏，本次修改不影响移动端。

## 三、影响范围

- 受影响文件：`themes/chic/source/css/custom.styl`（仅顶部导航栏布局相关规则）。
- 不涉及模板（`header.ejs`）、脚本（`source/js/script.js`）、站点配置（`_config.yml`）、主题配置（`themes/chic/_config.yml`）及部署流程。
- 影响范围：全站桌面端（≥1024px）顶部导航栏的水平对齐；不影响移动端布局、主题切换、移动端菜单、暗色/亮色配色。
- 外壳居中后，宽屏下导航条与正文共享同一视口中线（外壳 1360px、正文 1130px，均 `margin: 0 auto`），不再贴左。
- 侧轨改为 `1fr` 后理论上有压缩余量，但品牌与链接均为 `white-space: nowrap`，且 1024px 宽度下品牌+链接+操作总宽约 895px，仍有余量，无溢出风险。

## 四、验证结果

- `npm run build` 成功，262 个文件生成，无报错。
- 检查生成产物 `public/css/style.css`（经 hexo-neat 压缩）：
  - `.site-nav-shell` 含 `max-width:1360px;margin:0 auto;...grid-template-columns:minmax(0,1fr) auto minmax(0,1fr)...` ✓
  - 移动端断点：`.site-nav-shell{...grid-template-columns:minmax(0,1fr) auto...}`（不变）✓
  - `.site-brand` 含 `justify-self:start` ✓
  - `.site-nav-actions` 含 `justify-self:end` ✓
- 本地 `hexo s` 实测请求 `/css/style.css`，上述规则均与生成产物一致。
- 预期效果：桌面端导航外壳在视口水平居中，链接组在壳内居中（即落在视口中线），品牌贴左、主题切换按钮贴右。
