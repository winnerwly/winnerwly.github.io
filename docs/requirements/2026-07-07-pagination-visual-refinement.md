# 分页器视觉精修开发文档

## 需求名称

分页器视觉精修

## 一、需求背景

用户在归档页 `/archives/` 通过浏览器评论指出分页器“太丑了”。当前分页器由多个独立方形按钮组成，按钮之间间距较散，当前页使用高饱和绿色实心块，和归档页整体克制、清爽的页面气质不够统一。

## 二、需求目标

- 优化归档页底部分页器的视觉观感。
- 保持分页功能和链接结构不变。
- 让分页器更像一个整体控件，而不是散落的小按钮。
- 深色和浅色主题下均保持清晰、克制、易点击。
- 移动端保持紧凑，不产生横向溢出。

## 三、需求范围

涉及文件：

- `themes/chic/source/css/custom.styl`

涉及页面：

- `/archives/`
- 分类列表分页页
- 标签列表分页页

不包含：

- 不修改 `_partial/paginator.ejs` 的分页结构。
- 不修改 Hexo 分页配置。
- 不调整文章列表、归档列表和页面头图。

## 四、现状分析

分页模板位于 `themes/chic/layout/_partial/paginator.ejs`，当前输出结构包含：

- `nav.pagination`
- `a.extend.prev` / `a.extend.next`
- `a.page-number`
- `span.page-number.current`
- `span.space`
- `span.disabled`

样式主要由 `themes/chic/source/css/custom.styl` 中 `.pagination` 覆盖。当前样式的问题是视觉元素分散、按钮边框偏重、当前页绿色块过于突出。

## 五、技术方案

- 将 `.pagination` 外层调整为整体条状容器，使用轻微背景、边框和统一内边距。
- 缩小页码按钮之间的间距，增强整体性。
- 将页码按钮调整为更轻的胶囊样式。
- 当前页改为绿色文字与浅绿色背景，不再使用突兀的大色块。
- 上一页/下一页箭头保持独立但与整体条统一。
- 省略号保持轻量，不显示按钮边框。
- 浅色主题增加对应背景和边框适配。
- 移动端压缩尺寸和间距，保证不横向溢出。

## 六、影响范围

直接影响所有使用 `_partial/paginator.ejs` 的分页页面。由于选择器限定在 `.pagination` 内，不影响文章详情页的上一篇/下一篇导航。

## 七、风险评估

风险较低。该修复只改样式，不改分页结构和链接逻辑。主要风险是移动端宽度不足，因此需要验证 390px 左右宽度下的分页器是否仍然完整显示。

## 八、测试重点

- `npm run build` 构建通过。
- `/archives/` 分页器视觉更统一。
- 当前页、普通页码、上一页、下一页、省略号状态清晰。
- 浅色主题和深色主题均可读。
- 移动端无横向溢出。
