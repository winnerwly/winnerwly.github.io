# 主题切换按钮视觉修复开发文档

## 需求背景

用户截图反馈当前主题切换按钮“很奇怪”。现状表现为：

- 浅色模式下，按钮看起来像一个突兀的大黑圆。
- 深色模式下，月亮状态图标不够清晰，按钮不像常见主题切换控件。

该问题来自上一轮将文字按钮改为图标按钮后的视觉实现：当前使用圆形按钮加 CSS 阴影绘制图形，状态识别不够自然。

## 需求目标

1. 将主题切换按钮改为更常见、更易识别的胶囊式 icon toggle。
2. 浅色模式下显示清晰的太阳/亮色状态，不再出现大黑圆。
3. 深色模式下显示清晰的月亮/暗色状态。
4. 保留现有主题切换 JS 逻辑、`aria-label` 和 `title`。
5. 保持桌面端和移动端按钮尺寸协调。

## 当前状态分析

1. `themes/chic/source/css/custom.styl` 中 `.theme-toggle` 是 42px 圆形按钮。
2. `.theme-icon` 使用 `box-shadow` 绘制日/月效果，浅色状态下多个阴影叠加后视觉过重。
3. JS 已通过 `data-theme-mode` 标记当前模式，可直接用 CSS 根据状态渲染不同视觉。

## 实施方案

1. 只修改 `themes/chic/source/css/custom.styl`。
2. 将 `.theme-toggle` 改为胶囊形按钮：
   - 桌面端约 `54px × 32px`。
   - 移动端约 `48px × 30px`。
3. `.theme-icon` 改为滑块圆点：
   - 深色状态滑块在左侧，显示月亮感。
   - 浅色状态滑块在右侧，显示太阳感。
4. 用 `:before` 或 `box-shadow` 做轻量细节，不再使用夸张的外扩阴影。

## 受影响文件

- `themes/chic/source/css/custom.styl`
- `docs/requirements/2026-07-05-theme-toggle-visual-fix.md`

## 验证计划

1. 运行 `npm run build`。
2. 检查浅色模式顶部按钮不再是黑色大圆。
3. 检查深色模式顶部按钮显示清晰、尺寸协调。
4. 检查移动端主题按钮不挤压菜单按钮。

## 风险与取舍

1. 胶囊开关比纯图标按钮占用略多横向空间，但更符合主题切换的常见认知。
2. 不新增图标库或图片资源，继续用 CSS 绘制状态，避免引入依赖。
