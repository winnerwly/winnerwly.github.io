# 分类页按时间倒序排序

## 一、需求背景

当前访问 `http://localhost:4000/category/` 时，分类索引页的分类卡片按分类名称排序。由于分类中既包含年份分类，也包含“开篇”这类非年份分类，名称排序不能准确表达内容时间线，容易让最早的“开篇”分类出现在不符合预期的位置。

用户期望分类页按时间倒序展示，即最新内容对应的分类排在前面，最早内容对应的“开篇”分类排在最后。

## 二、需求目标

本次目标是调整分类相关页面的文章和分类排序规则：

- `/category/` 分类索引页按分类下最新文章日期倒序展示分类卡片。
- 分类卡片内的文章预览继续按文章发布时间倒序展示。
- 单分类页文章列表明确按发布时间倒序展示。
- “开篇”分类由于文章日期最早，应自然排在分类索引页最后。

本次不包含：

- 不调整文章 Front Matter 日期。
- 不修改文章内容。
- 不调整标签页、归档页、首页排序逻辑。
- 不重构 Hexo 构建或分页配置。

## 三、需求范围

本次涉及范围：

- `themes/chic/layout/category.ejs`
- `themes/chic/layout/_page/category.ejs`
- `/category/` 分类索引页
- `/category/:name/` 单分类文章列表页

不涉及范围：

- `source/_posts/` 下的文章内容。
- `themes/chic/source/css/` 样式文件，除非实际验证发现需要配合展示调整。
- GitHub Pages 部署配置。

## 四、现状分析

当前分类索引页模板中使用如下逻辑：

```ejs
site.categories.sort('name').forEach(function(category_item){ ... })
```

该逻辑会按分类名称排序，而不是按分类中的文章时间排序。

分类卡片内已有如下逻辑：

```ejs
category_item.posts.sort('date', -1).limit(3)
```

说明卡片内文章预览已经是时间倒序。

单分类页当前使用：

```ejs
page.posts.each(function (post) { ... })
```

该逻辑依赖 Hexo 传入的 `page.posts` 顺序。为避免生成结果受分页器或集合默认顺序影响，本次应在模板中显式按 `date` 倒序。

## 五、技术方案

### 5.1 分类索引页排序方案

在 `themes/chic/layout/category.ejs` 中，将 `site.categories.sort('name')` 调整为基于分类最新文章日期的倒序排序。

建议逻辑：

- 对每个分类取 `category_item.posts.sort('date', -1).first()` 作为该分类最新文章。
- 使用最新文章的 `date` 时间戳进行倒序比较。
- 如果分类没有文章，则排在最后。
- 为减少模板内重复排序，可在循环前生成排序后的分类集合。

### 5.2 单分类页排序方案

在 `themes/chic/layout/_page/category.ejs` 中，将 `page.posts.each(...)` 调整为 `page.posts.sort('date', -1).each(...)`，确保单分类文章列表始终按发布时间倒序展示。

### 5.3 验证方案

开发完成后执行：

```bash
npm run build
```

并检查生成后的：

- `public/category/index.html`
- 至少一个单分类页，例如 `public/category/2026/index.html` 或当前实际生成路径。

重点确认：

- `/category/` 首位应为最新文章所在分类，例如当前文章数据中应优先展示 `2026`。
- “开篇”分类因只有最早文章，应排在最后。
- 单分类页文章列表日期从新到旧排列。

## 六、影响范围

影响页面：

- `/category/`
- `/category/:name/`

影响行为：

- 分类卡片顺序从“按名称排序”变为“按分类最新文章日期倒序排序”。
- 单分类页文章顺序显式固定为时间倒序。

不应影响：

- 文章详情页。
- 标签页。
- 归档页。
- 首页。
- 构建配置和部署流程。

## 七、风险评估

- 如果部分分类没有文章，需要避免取日期时报错，应将空分类排在最后。
- Hexo 的集合排序方法会返回集合对象，模板中多次排序可能影响可读性，需要保持实现简单清晰。
- 如果未来分类不再按年份命名，本方案仍以真实文章时间为准，符合内容时间线预期。
- 若用户实际期望的是分类名称按年份数字倒序，而不是按最新文章时间倒序，需要在开发前重新确认。

## 八、测试重点

- 分类索引页分类卡片按最新文章时间倒序。
- “开篇”分类展示在最后。
- 分类卡片内文章预览仍按时间倒序。
- 单分类页文章列表按时间倒序。
- 页面无模板报错、无空白内容。
