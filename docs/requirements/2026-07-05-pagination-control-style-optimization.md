# 分页控件样式优化

## 一、需求背景

当前归档分页控件在 `/archives/page/2/` 等分页页面中视觉较弱，按钮尺寸、边框、间距和当前页状态与新版深色主题不够统一。截图中分页区域虽然可用，但整体像默认按钮排列，缺少与内容面板、主题色和交互状态的协调。

## 二、需求目标

本次目标是优化全站分页控件的视觉体验，使其在归档、分类、标签等分页页面中保持统一、清晰、易点击。

## 三、需求范围

### 3.1 本次包含

- 优化分页按钮尺寸、圆角、边框、背景、间距和字体层级。
- 强化当前页状态，使当前页与普通页清晰区分。
- 增加 hover、focus-visible 等交互状态。
- 兼容深色主题和浅色主题。
- 优化移动端排列，避免按钮挤压或溢出。

### 3.2 本次不包含

- 不改变分页数量、分页逻辑和路由规则。
- 不新增上一页、下一页按钮，除非现有模板已输出。
- 不调整文章列表、归档时间线和分类标签页面主体结构。

## 四、现状分析

分页由 `themes/chic/layout/_partial/paginator.ejs` 统一输出，当前配置 `prev_next: false`，生成页码按钮。基础样式位于 `themes/chic/source/css/_partial/paginator.styl`，新版页面样式中又在 `themes/chic/source/css/custom.styl` 增加了覆盖规则。

目前问题主要包括：

- 页码按钮边框和背景较单薄，与内容区没有明确视觉层级。
- 当前页只使用绿色背景和底部线条，细节不够统一。
- hover 与 focus 状态不足，不利于鼠标和键盘访问。
- 移动端缺少更紧凑的尺寸控制。

## 五、技术方案

- 优先在 `themes/chic/source/css/custom.styl` 中覆盖分页样式，减少对原主题基础文件的侵入。
- 保持 `.pagination`、`.page-number`、`.current` 等 Hexo 生成结构不变。
- 将分页容器调整为居中、可换行的按钮组。
- 将页码按钮设计为统一的方形/胶囊按钮，使用固定最小尺寸，避免数字变化导致布局跳动。
- 当前页使用主题绿色背景、深色文字和轻微阴影。
- 普通页使用半透明背景、细边框和低饱和文字，hover 时提升边框、文字和背景亮度。
- 浅色主题下使用浅背景、深文字和绿色当前页。

## 六、影响范围

影响使用 `_partial/paginator.ejs` 的页面，包括：

- `/archives/` 及其分页页面；
- 分类文章列表分页页面；
- 标签文章列表分页页面；
- 其他复用该分页片段的页面。

不影响文章详情页上一篇/下一篇导航，也不影响站点路由生成逻辑。

## 七、风险评估

- 如果样式选择器过宽，可能影响文章详情页导航，因此需要限定在 `.pagination` 内。
- 如果移动端按钮宽度过大，可能出现换行过多，需要设置合理间距和尺寸。
- 如果浅色主题对比度不足，需要单独补充 `.light-theme` 规则。

## 八、测试重点

- 验证 `/archives/page/2/` 分页显示正常。
- 验证 `/archives/`、分类分页、标签分页页面样式一致。
- 验证当前页、普通页、hover、focus-visible 状态。
- 验证桌面端和移动端不溢出、不遮挡、不跳动。
- 执行 `npm run build`，确认构建无错误。
