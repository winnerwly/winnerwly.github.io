# 文章详情页样式深度优化

## 一、需求背景

用户要求“所有文章的内页”也需要优化。当前文章详情页路径示例：

- `http://localhost:4000/2026/04/20/2604201000/`

首页和部分内容页已经进入新深色产品风设计方向，但文章详情页仍保留旧模板结构和旧样式。当前存在元信息乱码、发布时间重复输出、上下篇导航视觉陈旧、正文排版不够统一、代码块和目录样式与新主题不一致等问题。

## 二、需求目标

本次目标是统一所有文章详情页的阅读体验：

- 修正文章详情页模板中的可见乱码文案。
- 优化文章标题、作者、发布时间、分类、标签等元信息展示。
- 优化正文排版，包括段落、标题、列表、引用、表格、图片、代码块。
- 优化右侧目录样式，使其与新主题一致。
- 优化上一篇/下一篇导航，去除旧图片箭头，改为文字与边框卡片式导航。
- 保持深色与浅色模式一致。
- 保持字号规范化，不新增随意字号。

## 三、需求范围

### 3.1 本次包含

- 优化所有文章详情页模板。
- 修正 `themes/chic/layout/_page/post.ejs` 中的中文文案乱码。
- 修复发布时间重复显示问题。
- 优化文章正文样式。
- 优化代码块、引用、图片、表格、列表展示。
- 优化文章目录 `toc` 样式。
- 优化上一篇/下一篇导航。
- 完成后运行 `npm run build` 验证。
- 完成后新增开发总结到 `docs/reviews/`。

### 3.2 本次不包含

- 不修改历史文章正文内容。
- 不批量修复历史文章 Markdown 的编码问题。
- 不新增评论系统。
- 不新增阅读进度、点赞、分享等交互功能。
- 不引入第三方 UI 框架。
- 不处理当前工作区已有的其他无关改动。

## 四、现状分析

当前相关文件如下：

- `themes/chic/layout/_page/post.ejs`：文章详情页模板，存在作者、发布时间、分类、标签等可见文案乱码；发布时间输出中时间被重复渲染。
- `themes/chic/source/css/_page/_post/post_header.styl`：旧文章头部样式，字号和颜色体系与新主题不一致。
- `themes/chic/source/css/_page/_post/post_content.styl`：旧正文样式，正文行高、代码块、引用、表格等需要统一优化。
- `themes/chic/source/css/_page/_post/post_nav.styl`：旧上下篇导航使用 base64 图片箭头，视觉不适合当前主题。
- `themes/chic/source/css/_page/_post/post_toc.styl`：目录样式较旧，需要统一为深色产品风。
- `themes/chic/source/css/custom.styl`：已有当前主题覆盖样式和字号变量，可作为主要优化入口。

## 五、技术方案

### 5.1 模板方案

- 调整 `post.ejs` 的元信息结构，使用中文标签：
  - 作者；
  - 发布时间；
  - 分类；
  - 标签。
- 修复发布时间重复输出，只保留日期与时间各一次。
- 将标签与分类展示为可点击的轻量标签样式。
- 隐藏或移除旧的 `post-tags` 内联隐藏区域，避免无效结构。
- 上下篇导航保留功能，但改成更清晰的卡片结构和中文辅助文案。

### 5.2 正文样式方案

- 在 `custom.styl` 中统一文章页样式，尽量减少对旧样式文件的大范围改动。
- 使用已有字号变量：
  - 正文 `$text-base`；
  - 文章标题 `$text-section` 或更大一级；
  - 二级标题 `$text-2xl`；
  - 三级标题 `$text-xl`；
  - 辅助信息 `$text-sm`。
- 统一段落行高、标题间距、列表间距、图片边框、表格边框、引用块背景。
- 优化代码块横向滚动、内边距、背景和字体。

### 5.3 目录与导航方案

- 优化 `.post-toc`，使用统一边框、背景、文字颜色和激活态。
- 小屏继续隐藏目录，避免遮挡正文。
- 将 `.post-nav` 改为双卡片布局，移动端堆叠显示。
- 去除旧 base64 箭头图片，使用文字提示“上一篇”“下一篇”。

## 六、影响范围

可能影响的文件：

- `themes/chic/layout/_page/post.ejs`
- `themes/chic/source/css/custom.styl`
- 必要时涉及：
  - `themes/chic/source/css/_page/_post/post_header.styl`
  - `themes/chic/source/css/_page/_post/post_content.styl`
  - `themes/chic/source/css/_page/_post/post_nav.styl`
  - `themes/chic/source/css/_page/_post/post_toc.styl`

影响页面：

- 所有文章详情页；
- 带目录的文章详情页；
- 带分类和标签的文章详情页；
- 有上一篇或下一篇的文章详情页。

不影响首页、独立页面、归档聚合页的业务逻辑。

## 七、风险评估

- 文章详情页数量较多，样式变更会影响全部文章，需要通过构建和抽样页面验证。
- 如果选择器过于宽泛，可能影响普通页面的 `.post-content`，需要控制范围或确认这类统一影响是可接受的。
- 历史文章包含图片、表格、代码块、HTML 示例等复杂内容，需要注意不要破坏渲染。
- 目录定位为 fixed，如果样式或尺寸不当，可能遮挡正文或在小屏溢出。

## 八、测试重点

开发完成后需要验证：

- `npm run build` 通过。
- 示例文章 `/2026/04/20/2604201000/` 标题、元信息、正文展示正常。
- 作者、发布时间、分类、标签文案为中文且无重复时间。
- 代码块、引用、表格、图片、列表展示正常。
- 带目录文章的目录位置和激活态正常。
- 上一篇/下一篇导航在桌面端和移动端都可用。
- 深色与浅色模式下正文可读性正常。
