# 分页选择器标准样式调整

## 一、需求背景

当前分页控件虽然已经具备按钮化样式，但视觉仍然偏重，当前页阴影和绿色块过于抢眼，整体不像常见后台、博客和内容站点中的标准分页选择器。用户反馈“还是很丑”，希望参考常见分页选择器设计重新调整。

## 二、需求目标

将分页控件调整为更标准、克制、规整的分页选择器样式，使其在 `/archives/`、归档分页、分类分页和标签分页中更自然地融入内容面板。

## 三、需求范围

### 3.1 本次包含

- 重新调整 `.pagination` 的间距、按钮尺寸和视觉权重。
- 普通页码使用白色或半透明底、浅边框、深灰文字。
- 当前页使用主题绿色实心按钮，但降低阴影和装饰感。
- 省略号使用无边框、弱化文字样式。
- hover 状态保持轻量，不使用明显位移和重阴影。
- 保留浅色主题和移动端适配。

### 3.2 本次不包含

- 不调整分页逻辑和分页数量。
- 不新增上一页、下一页、跳转输入框或每页条数选择器。
- 不调整归档、分类、标签主体内容结构。
- 不修改文章详情页上一篇/下一篇导航。

## 四、现状分析

分页由 `themes/chic/layout/_partial/paginator.ejs` 输出，当前结构包含：

- `a.page-number`：可点击页码；
- `span.page-number.current`：当前页；
- `span.space`：省略号。

当前样式位于 `themes/chic/source/css/custom.styl`，包含绿色当前页、较明显阴影和 hover 位移。该风格在页面底部显得突兀，尤其在浅色背景和大面积留白下不够精致。

## 五、技术方案

- 继续只在 `themes/chic/source/css/custom.styl` 中调整分页样式。
- 将按钮尺寸控制在常见分页器范围：桌面端约 `40px`，移动端约 `34px`。
- 普通按钮使用 `border-radius: 6px`、浅边框、安静背景。
- 当前按钮使用绿色背景、深色文字、轻微边框，不再使用大面积投影。
- hover 只改变边框、文字和背景，不再使用 `transform`。
- `.space` 不使用按钮边框，保持省略号轻量显示。

## 六、影响范围

影响所有使用 `_partial/paginator.ejs` 的分页页面，包括：

- `/archives/`
- `/archives/page/2/`
- 分类分页页面；
- 标签分页页面。

不影响普通文章详情页导航和站点路由。

## 七、风险评估

- 如果按钮颜色过浅，深色主题下可能对比不足，需要分别处理深色和浅色主题。
- 如果当前页过于低调，用户可能不易识别当前位置，需要保留明确实心状态。
- 如果移动端按钮间距过大，可能换行过多，需要单独设置小屏尺寸。

## 八、测试重点

- 验证 `/archives/` 中 `1 2 3 … 5` 的显示效果。
- 验证 `/archives/page/2/` 当前页切换后的样式。
- 验证分类、标签分页页面复用正常。
- 验证深色主题和浅色主题可读性。
- 执行 `npm run build`，确认构建无错误。
